### Pro 5x：适合经常用 ChatGPT 写代码和处理长任务

Pro 5x 的定位比 Plus 更偏向高频工作流。常见使用场景包括：

## 充值后没有到账，应该怎么处理

### 先看 WildAI 订单状态

平台一般会在“我的订单”或 AI 订阅页面显示处理状态。常见状态包括处理中、已完成、失败或退款。

如果订单仍然是处理中，先等待页面给出的处理时间。重复付款会让客服更难判断哪一笔订单对应哪个账号。

### 再检查 ChatGPT 账号

确认你查看的是提交时使用的同一个 ChatGPT 账号。很多“没有到账”的情况，最后是因为用户登录了另一个邮箱。

可以检查：

- ChatGPT 当前登录邮箱；
- ChatGPT 设置中的订阅状态；
- 当前方案名称；
- 下一个账单日期；
- WildAI 订单中的账号邮箱。

### 失败后不要自行反复支付

平台帮助中心写明，部分订阅失败订单会自动退款，但退款进度应以平台订单和支付渠道状态为准。已经扣款但没有生效时，先保存订单号、支付记录和账号套餐截图，再联系客服核对。

如果订单已经完成履约，之后因为选错套餐、买错账号或个人原因不想使用，通常不一定支持退款。平台公开的退款规则明确提到，已生效权益原则上不支持因个人原因退款；仍在处理、尚未生效或存在系统异常时，才更适合联系客服确认。
